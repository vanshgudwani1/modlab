# Modlab Asset Guide

## 1. AI Output Assets
- **Resolution**: 1024x1024 (Square) minimum.
- **Format**: PNG (preferred) or JPG (high quality).
- **Background**: Transparent optional (depending on style).
- **Storage**: `public/ai-outputs/`
- **Naming**: `[creation_id].png`

## 2. Store Product Assets
- **Product Preview**: High-fidelity renders or photos.
- **Box Mockup**: "Comic box" style packaging render.
- **Recommended Size**: 800x1200 (Portrait) or 1000x1000 (Square).
- **Storage**: `public/products/`
- **Naming**: `[product_slug]_[view].jpg`

## 3. Drop Assets
- **Banner**: 1920x600 (Hero banner).
- **Countdown Thumbnail**: 600x600.
- **Badges**: 'Limited Edition', 'Sold Out' overlays (SVG/PNG).
- **Storage**: `public/drops/`

## 4. 3D Assets (Future-ready)
- **Format**: .glb (Binary glTF).
- **Size Limit**: Max 2MB per file (optimized for web).
- **Storage**: `public/models/`

## 5. Branding Assets
- **Logo**: SVG format (Vector).
- **Favicon**: .ico or .png (32x32).
- **Storage**: `public/branding/`
